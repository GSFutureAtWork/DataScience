### Dicionário de Dados (Após ordenação e formatação)

| Variável           | Tipo       | Descrição                                                                              |
| :----------------- | :--------- | :------------------------------------------------------------------------------------- |
| job_title          | categórica | Cargo ou título da função (ex: Data Engineer, Data Scientist, ...)                     |
| experience_level   | categórica | Nível de experiência (EN: Entry-level, MI: Mid-level, SE: Senior-level, EX: Executive) |
| employment_type    | categórica | Tipo de contrato (FT: Full-time, PT: Part-time, CT: Contract, FL: Freelance)           |
| company_location   | categórica | País de localização da sede da empresa (ex: United States, Germany)                    |
| company_size       | categórica | Porte da empresa (S: Small/Pequena, M: Medium/Média, L: Large/Grande)                  |
| employee_residence | categórica | País de residência do profissional (ex: United States, Brazil, India)                  |
| remote_ratio       | numérica   | Percentual de trabalho remoto (0: On-site, 50: Hybrid, 100: Remote)                    |
| work_year          | numérica   | Ano de referência do salário (ex: 2023, 2024)                                          |
| salary_in_usd      | numérica   | **TARGET**: Salário anual em Dólares Americanos (USD)                                  |
